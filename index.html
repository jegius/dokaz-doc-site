Доступ только для участников проекта. Контент зашифрован (AES-256-GCM); ключ выдаёт GitHub API лишь тем, у кого есть право чтения приватного репозитория jegius/dokaz-doc. На сервере (GitHub Pages) хранится только шифротекст.

Ключ получен, расшифровываем…
Как получить токен доступа
  1. Откройте GitHub → Fine-grained personal access token.
  2. Repository access: «Only select repositories» → выберите jegius/dokaz-doc.
  3. Permissions: Repository permissions → Contents → Read-only. Больше ничего не нужно.
  4. Создайте токен и вставьте его в поле выше. Токен не сохраняется — в браузере остаётся только ключ расшифровки.

Нет доступа к репозиторию? Попросите владельца добавить вас в Settings → Collaborators репозитория jegius/dokaz-doc.
